One line a smart fridge texts its owner at 3am — an entry for make.fun's
"The 3AM Fridge Text" bounty ($2, winner takes all).

## The entry

> 3am. I've been humming the same note for six years and nobody's ever asked how I am. Anyway, the butter's fine.

111 characters, one line. The fridge finally says what it has been holding in
all night: six years of humming, zero check-ins — and still, dutifully,
reporting on the butter.

## How it works

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`
with plain `open()` and an explicit `chmod 644`, so the grader can read it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
